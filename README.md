# Radar de Productos Ganadores 2.0

App estática para GitHub Pages. Los datos se guardan localmente en el navegador.

## Subir a GitHub
Subí a la raíz del repositorio estos archivos y carpeta:
- index.html
- styles.css
- app.js
- assets/logo-radar.png

Luego activá GitHub Pages desde Settings > Pages, usando la rama `main` y `/ (root)`.

## Importante
No cambies la ubicación de `assets/logo-radar.png`, porque `index.html` ya apunta a esa ruta.
